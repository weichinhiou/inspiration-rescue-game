# 靈感搶救戰｜v7.4.4

純 HTML、CSS、JavaScript 的單機小遊戲原型，沒有套件安裝步驟，也不會把分數或輸入內容送到伺服器。

## 本機預覽

解壓縮後，直接雙擊 `index.html`，即可用瀏覽器開啟遊戲。此原型只使用同資料夾內的 HTML、CSS、JavaScript，不需要安裝套件或啟動 Python 伺服器。

若想模擬網站環境，也可以選擇用任何本機靜態伺服器預覽；這不是必要步驟。

## GitHub Pages

將 `index.html`、`styles.css`、`game.js`、`assets/` 和 `README.md` 放在儲存庫根目錄，推送後在 GitHub 儲存庫的 **Settings → Pages** 選擇從 `main` 分支的根目錄部署。頁面使用相對路徑載入 CSS、JavaScript 與圖片，可用於 `https://<帳號>.github.io/<儲存庫>/` 這類專案頁面。

## 圖片載入紀錄

圖片首次載入偏慢的原因、ast.webp 壓縮處理、驗證範圍與後續測試清單，請見 [docs/LESSONS_LEARNED.md](docs/LESSONS_LEARNED.md)。

## 目前原型內容

- 60 秒單機回合、即時分數與連擊提示
- 開始遊戲前有 3、2、1 倒數；倒數結束才開始計時與生成物件
- 左上角以基礎靈感燈泡插畫作為遊戲標誌
- 點擊開始後先顯示圖像化物件圖例，玩家確認後才進入倒數
- 加大 HUD、物件標籤、說明卡與結算視窗文字，提升手機及桌面可讀性
- 以暖木桌與藍灰色布面書寫墊呈現完整遊戲場景，靈感、紅色干擾物與加倍道具使用獨立透明插畫；九個互動位置呈現為桌面洞口
- 桌面控制項改用半透明的暖紙色 HUD 與便條材質，保留背景插畫的可視範圍；直式手機使用獨立構圖的桌面背景
- 電腦版左右遊戲區頂端對齊；手機版縮短洞口區高度、置中洞口標號，讓開局按鈕更容易留在首屏
- 遊戲進行時，電腦版游標移到洞口會顯示放大的核准 v8 預備姿勢遊戲槌並跟隨；按下或手機點擊時切換為近乎水平的擊打姿勢，槌墊接觸桌面時出現星星效果，桌面同步短暫震動
- 開局立即同時出現 2 個靈感與 2 個紅標干擾物，場上最多 4 個靈感、3 個紅標
- 約 7% 的靈感會成為罕見星光靈感，點中 +3 分並照常收集字母
- 藍色筆記本道具每次加 5 秒，沒有加時上限；藍色懷錶讓後續生成間隔放慢 3 秒
- 新增「同仁一起討論」道具圖：每局優先出現，漏接後隔幾波重現；收下後 +3 分、隨機補上一個目前缺少的名句字母、+3 秒
- 遊戲中可按「暫停」，查看與開局相同的物件圖例；回到遊戲後，回合倒數、物件消失與下一波生成都從暫停處繼續
- 臨床急件約占紅標生成的 10%，會隨機顯示「臨時約診／臨床案件／緊急交班」；誤點扣 5 秒並中斷連擊，不扣分、不偷字母
- 紅色干擾詞庫包含電話、會議、待辦、刀房通知與交資料；洞口編號只在空洞口顯示，避免與物件插畫重疊
- 加時、慢速與既有 ×2 道具共用特殊物件生成位，一次最多出現一個；×2 僅套用於分數加減
- 每 20 秒逐步加快出現頻率、縮短黃色靈感停留時間；最後 20 秒增加紅標數量，讓難度隨回合平緩上升
- 點中靈感 +1 分；連續接住 5 個額外 +2 分
- 誤點電話、會議或待辦紅標 −2 分（可扣至負分），隨機失去一個已收集字母，連擊歸零，另一個靈感會移到新位置
- 同類靈感在筆記本疊成同一疊，便條視覺厚度隨數量增加，並標示 ×N 與收集到的字母
- 每局隨機抽一則 Poor Richard 格言，收集整句所需的英文字母；字母順序不限，但重複字母要逐張收齊，完成依字數獲得大額獎分
- 拼成名句時立即解鎖完整原文與繁體中文解讀，將名句變成一則可帶走的新靈感
- 場上會出現紫色「下次 ×2」特殊便條；下一次得分或扣分都會加倍
- ×2 道具使用透明底圖，洞口不再顯示多餘的淺色橢圓面板
- 靈感命中、紅標誤點與 ×2 各有合成音效，整體音量提高約 70%，右上角可關閉；瀏覽器首次開始遊戲後啟用音訊
- 點中靈感後飛進筆記本的動畫
- 結算出現後，關閉按鈕倒數 3 秒才啟用；倒數期間點背景或按 Esc 不會關掉成績
- 結算卡的返回按鈕標示「回到桌面看本局結果」
- 移除遊戲側欄「怎麼玩」區塊，讓名句拼圖直接接在靈感筆記本之後
- 頁面底部使用綠植任意門新版透明方向牌「回去任意門寫靈感」，縮小顯示並連往 https://ksvgh-anywhere-door.vercel.app/（新分頁）
- 手機版排版、鍵盤可操作按鈕及減少動態效果設定
- 沒有排行榜、登入、科別／職類分版或伺服器儲存

名句選自《Poor Richard's Almanack》格言段落的英文原文；素材已放在 `assets/`，遊戲不依賴外部圖床或伺服器。
